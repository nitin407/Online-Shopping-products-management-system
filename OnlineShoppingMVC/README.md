# Online Shopping Product Management System

Simple ASP.NET Core MVC project for CIE-2 Web .NET.

## Requirements covered

- Product model
- GetDiscountedPrice() extension method
- Async Fake Store API request
- Cookie for customer name
- Session for selected category
- Query string for ProductId
- Hidden field for ProductId
- MemoryCache for 10 minutes
- Response Caching for product details
- Bootstrap UI
- Simple comments for important code

## Run in VS Code

```bash
dotnet restore
dotnet run
```

Open the URL shown in the terminal.
